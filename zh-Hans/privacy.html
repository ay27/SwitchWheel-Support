我们如何处理信息

本政策说明转盘 macOS 应用、这些支持页面，以及你主动提交支持请求时的信息处理方式。

应用不会向开发者发送本机的键盘输入、运行应用列表、固定位置或应用切换历史。当前版本没有网络客户端权限，不包含广告、跟踪、云同步、开发者统计服务或内置分析 SDK。

本机保存的信息

为恢复你的配置并支持故障排查，应用会在 macOS 的本地应用偏好设置中保存以下信息：

信息用途
触发方式、修饰键、录制的快捷键及其显示名称识别你选择的唤出操作
固定位置、所选应用路径、安全作用域书签、暂存的固定位置配置恢复应用位置及你授予的只读访问
稳定的应用身份顺序避免每次切换后按最近使用顺序重排
主题、是否包含其他运行应用、引导完成状态保留界面与使用偏好
权限是否允许、监听是否运行、修饰键事件计数和应用版本本机故障排查

应用会在内存中读取运行应用的名称、身份、图标以及手势所需的鼠标位置，来绘制圆盘并切换应用。这些运行状态不会由本应用上传。应用身份顺序用于保持布局，并不是逐次切换的时间日志。

输入监控与应用访问

输入监控：长按模式通过只读事件监听识别设置的左侧修饰键，以及用于取消手势的其他按键或点击事件。监听可以接收按键按下事件，但应用不读取、记录或保存普通键盘输入的文字内容；不构建打字记录。修饰键事件计数保存在本机用于排查。

录制快捷键：你主动录制的组合键编码、修饰键及名称会保存为设置，以便再次触发圆盘。

文件访问：你选择或拖入固定位置的应用通过沙盒只读访问及安全作用域书签保留授权。该访问用于应用信息和图标，不授予任意文档内容访问权限。

本应用不请求屏幕录制或辅助功能权限，不捕获窗口预览或屏幕内容。

分享与第三方

当前应用没有将上述本地信息发送给开发者、广告商、数据经纪商或其他第三方的功能，也不出售或共享这些本地信息。

App Store 购买、退款、分发，以及由你选择参与的 Apple 系统诊断或 TestFlight 反馈，由 Apple 按其政策处理，不是应用内置的开发者分析服务。参阅 Apple 隐私政策。

保存、删除与控制

本地偏好设置会保留至被修改、重置或从 Mac 删除。你可在应用设置中移除固定应用、更改快捷键及主题；撤销“系统设置 → 隐私与安全性 → 输入监控”权限会停用长按模式。将固定位置数量设为 0 仅关闭该功能，不等于删除全部历史配置。

卸载应用后，macOS 可能仍保留偏好设置。需要完整重置的对应版本步骤时，可通过支持入口联系我们。开发者未收到这些本地数据，无法远程查看或清除它们。应用没有需要注销的账号。

网站与支持请求

本网站托管于 GitHub Pages，页面本身不设置分析、广告、表单、Cookie 或本地存储。此网站使用账号既有的 ay27.com 域名，并由 Cloudflare 提供代理服务。GitHub 与 Cloudflare 可能按各自政策处理访问请求信息（例如 IP 地址和访问日志）；参阅 Cloudflare 隐私政策及 GitHub 隐私声明。

当你主动在 GitHub Issues 提交问题时，你提交的账号名称、文字及附件会由 GitHub 处理，并在公开问题中显示。开发者仅使用你提供的内容来答复、排查问题或维护应用。请勿在公开问题中发布私人或敏感信息。

你可以使用 GitHub 的编辑、删除及隐私控制来管理自己提交的内容，也可以通过支持入口请求我们处理隐私问题；开发者无法控制 GitHub 按其政策保留的信息。

政策变更与联系

如果数据处理方式发生变化，我们会更新本页的生效日期，并在适当情况下通过版本说明提示。新增联网、同步或分析等功能前，也会相应更新政策与商店隐私声明。
